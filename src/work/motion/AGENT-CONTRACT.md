# Motion Lab implementation contract

Each agent owns only its assigned `<slug>.jsx` and `<slug>.css`. Export a default React page, import its CSS. The parent creates the HTML route, mount, toolbar, gallery, and shared scene lifecycle. Do not edit shared files, package files, or other designs. Do not create more agents.

Use React and `motion/react` for staggered headings, spring gestures, scroll transforms, and real state transitions. Use `useMotionEnabled` from `./runtime.jsx`; disable continuous/scroll/pointer movement when false. One functional meaningful interaction per design minimum. Every navigation/CTA resolves to a real local section or state; no dead `#` or external pretend checkout.

Shared 3D: `import Scene from './Scene.jsx'`. Usage: `<Scene build={buildScene} settings={{ variant }} label="Description of sculpture" className="custom-class" />`. Define `buildScene` at MODULE SCOPE, not inside React. It receives `{ THREE, scene, camera, renderer }`. Scene is transparent with studio lighting, reflection environment, camera at (0,0,7), fov 35; you may reposition camera. Add your geometry to scene. Return `{ update({time, delta, pointer, settings, reducedMotion}) {}, dispose() {} }`. Pointer is normalized `{x,y}`; settings always latest; time freezes when motion paused. Parent handles resize, DPR <=1.5, offscreen pause, animation loop, GPU cleanup, context failures, reduced motion. `dispose` is optional for extra resources. Geometries/materials/textures in scene are automatically disposed. Use actual distinctive Three.js geometry, not only CSS spheres. Tune objects to fit camera. No remote textures/models. Container must have explicit height or fill a position:relative parent. `.motion-scene` has width/height100%, canvas fills; override scoped class if needed.

All CSS scoped with unique design prefix, except body background via `body:has(.your-root)`. Default root reset/font supplied. Google fonts may be loaded with CSS @import before other rules. No nav toolbar needed: parent adds global bottom toolbar. Allow bottom padding >=90px. Responsive at 375,768,1440; h1 once, a real main element id=main; no hidden critical content. Text >= contrast4.5:1, buttons at least44px. Avoid generic stacked cards: each page is an original art-directed composition. Provide a second meaningful section where appropriate. Build original code based on assigned reference direction, never copy website assets. No tests or commits required; parent performs browser checks. Read framer-motion and karpathy skills if needed.
