CurricuLearn

A platform for Ontario K-12 teachers to generate curriculum-aligned classroom material with AI. Pick the grade, subject and curriculum expectations, then generate worksheets, quizzes, lesson plans, slides and more - streamed token by token. Teams, classes, a shared library, Google Docs and Classroom, English and French, and Stripe billing across Free, Pro and Enterprise.

RoleFull-stack developer
StackGraphQL API · Server-Sent Events streaming · Stripe subscriptions · Google Docs / Classroom
ContentLicensed Ontario curriculum data (Grades 1-12) with a strands → overall → specific expectation browser
01

Teacher dashboard

Set the curriculum context - grade, subject, expectation - and the creation tools unlock. Recent worksheets sit below.

02

Create with AI

Nine generators: worksheets, quizzes, exit tickets, lesson plans, flashcards, assignments, rubrics, activity ideas and slides - each with its own settings.

03

Curriculum expectations

The Ontario expectation browser: pick Grade 3 Mathematics, expand a strand, select the exact expectations the material must cover. Bilingual output.

04

Generated worksheet

Questions stream in as they're written. Edit, print, export to PDF or Google Docs, or assign straight to a class.

05

Teams and plans

Multi-organization workspaces with role-based access; team collaboration unlocks on the Enterprise tier via Stripe billing.
