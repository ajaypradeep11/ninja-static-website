# LocalNinja Studio business card — v1

Two-sided studio card generated with the built-in image generation tool on 2026-11-05. The website's blue ninja logo served as the reference. Brand colours are deep navy and LocalNinja blue; the reverse lists the studio's services and public contact details.

- [Front PNG](localninja-card-front-v1.png)
- [Back PNG](localninja-card-back-v1.png)
- [Two-page PDF proof](localninja-business-card-v1.pdf): front followed by back, each page 3.5 × 2 inches.
- [Exact generation prompts and reference path](prompts.json)

Each original PNG is 1659 × 948 pixels, a 7:4 aspect ratio, equivalent to 474 pixels per inch at the card's trim size. The PDF embeds the artwork at this physical size. This is an RGB design proof; printer-specific bleed and colour conversion are not included.

Contact copy uses `studio.localninja.ca` and `support@localninja.ca`. No personal name, phone number or street address was added. The six service groups cover UI/UX, web and e-commerce, AI and voice bots, custom software, consulting, and maintenance/support.

Original generated PNGs remain in the generator's output directory. The workspace copies above preserve them without image edits. The PDF was exported from the two images using Chromium.
